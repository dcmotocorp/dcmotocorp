# Mission Guard Industrial Monitoring

**Stack:** Django REST Framework, Python, Docker, Kafka, InfluxDB

## Problem
Industrial environments needed APIs and networking functionality to observe connected devices and support operational security workflows.

## My contribution
- Developed REST APIs and reusable networking modules for device data exchange and monitoring.
- Built an administrator terminal application to inspect and change device network configurations.
- Integrated Dockerized services with Kafka and InfluxDB components.

## Outcome
These components supported industrial device monitoring and administrative workflows. This page does not claim a particular detection rate, security certification, or deployment scale.

## Design considerations
- Separate device communication from API-facing workflows.
- Validate administrative operations and surface errors clearly.
- Keep the telemetry pipeline observable and containerized.

This is a high-level case study of professional work. Source code, network details, and client data are private.
